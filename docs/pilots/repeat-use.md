# P27 — Voluntary return ledger

**Status:** **incomplete / unvalidated**  
**Updated:** 2026-10-04

## Rule

Count only hosts who:

1. Were offered a normal chance to plan another outing
2. Started without mandatory study instructions
3. Completed without the founder entering member inputs

Scheduled research sessions are logged separately and **do not** satisfy the return gate.

8/12 hosts voluntarily start and complete a subsequent real event.
