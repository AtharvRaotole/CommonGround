# Neutral shortlist cards (blind kit)

Print or paste into a shared doc. Replace bracketed fields after ranking. **Do not** include method names, affinities, or "AI picked this."

---

## Card template (one venue)

```
OPTION [1|2|3] — Method [X]

Name: _______________
Neighborhood: _______________
Category: _______________
Price band (estimate): $ / $$ / $$$ / $$$$
Why it might work for this group (facts only, ≤40 words):
…
What is still unverified:
…
Source link (official):
…

Willingness to attend this option (1 = no way, 5 = definitely):
Your score: __
```

---

## Blind packet cover

```
Outing: [title] — [date]
Group size: [n]
Constraints honored before taste: [list]
Methods: two different shortlists. Labels hidden until everyone scores.

Instructions:
1. Read Method X options 1–3.
2. Score willingness for option 1 (required); 2–3 optional.
3. Read Method Y the same way.
4. Do not discuss scores with the group until host unlocks.
```

---

## Host blind preference (after members score)

```
Without knowing labels, which shortlist would you take to reservation research?
[ ] Method X
[ ] Method Y
[ ] Neither — explain
Any veto now? Venue id / reason category (taste|cost|distance|schedule|practical|prefer_not_to_say):
```
