# Next experiment (90-day bottleneck)

**Decision parent:** `docs/business/eight-week-review.md`  
**Owner:** founder · **Created:** 2026-10-04

## Hypothesis

If three real NYC hosts complete one outing each with live Qloo ranking (once the key arrives), we will learn whether private intake + ordinal shortlist beats their current thread **on active host time and acceptance** — before investing in billing or multi-city.

## Bottleneck addressed

**Not** “add integrations.” The demonstrated bottleneck is **missing live customer + provider evidence**, not missing UI surfaces.

## Plan (time/cost boxed)

| Window | Work | Cap |
|---|---|---|
| Days 0–3 after key | Live capability matrix + rights fixture path | 8 founder hours |
| Days 3–21 | Recruit 3 Path A/B hosts; run paired time study (P26 kit) | 24 hours |
| Days 21–45 | Offer test: 5 exact-offer conversations (P28) if rights allow | 10 hours |
| Days 45–90 | Only if ≥2/3 hosts accept product arm and ≥1 exact-offer intent: polish retention loop | 20 hours |

**Spend cap:** Cloudflare Free only · no paid Workers upgrade · OpenAI optional and metered off by default.

## Stop rules

Stop or pivot the **startup thesis** if any of:

1. Key denied / terms forbid required demo processing.
2. 0/3 hosts complete intake without researcher entry.
3. Hosts only succeed when founder does the work (service signal).
4. Commercial rights block charging and no alternate data path exists.
5. Zero budget-owner exact-offer intents after five clear asks.

## Pivot sketch (only if stop on buyer, not on tech)

New explicit job: **“host needs a shareable constraint checklist + calendar handoff”** without Qloo — only if Qloo rights fail but workflow pain remains. Requires a new decision record; do not silently drop taste ranking.

## Operations if abandoned

- Assign deletion: wipe preview D1 participant data; revoke invites.
- Rotate/remove provider keys from Worker secrets.
- Keep research docs; strip any residual PII.
- Owner: founder.
